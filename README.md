# Competition Digest

A lightweight Python utility that pulls data from Kaggle and Zindi, scores competitions against your interests, and sends a personalized digest by email.

It is designed for people who want a quick weekly or daily view of competitions that are relevant to their background and goals, without manually searching two platforms every time.

## What it does

- Fetches active competitions from Kaggle and Zindi
- Scores each competition against a keyword profile you define
- Highlights new items and deadline changes
- Produces an HTML report and CSV export
- Sends the results by email using Gmail SMTP
- Supports a dry-run mode for local previewing without sending email

## Why this project exists

The app focuses on relevance, not just volume. It uses a weighted keyword profile so competitions with strong matches for your interests, such as NLP, ML, vision, African language AI, or climate-related ML, rise to the top of the digest.

## Requirements

- Python 3.12+
- A Kaggle account with API credentials
- A Gmail account with app password support (2FA required)
- Internet access to call the Kaggle and Zindi APIs

## Setup

1. Clone the repository and open the project folder.
2. Create and activate a virtual environment:

```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS/Linux
source .venv/bin/activate
```

3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Create a local environment file based on the example:

```bash
copy env.example .env
```

Then update `.env` with your own values:

```env
KAGGLE_USERNAME=your_kaggle_username
KAGGLE_KEY=your_kaggle_api_key
GMAIL_USER=you@gmail.com
GMAIL_APP_PASSWORD=xxxx xxxx xxxx xxxx
REPORT_TO=you@gmail.com
```

Notes:

- `KAGGLE_USERNAME` and `KAGGLE_KEY` come from your Kaggle account API settings.
- `GMAIL_APP_PASSWORD` should be an app password generated from your Google account, not your main Gmail password.
- `REPORT_TO` is optional; if omitted, the report is sent to `GMAIL_USER`.

## Configuration

The main keyword profile is defined at the top of `competition_digest.py` in the `PROFILE_KEYWORDS` dictionary. This is the main place to tune what counts as a good match for your interests.

Example:

```python
PROFILE_KEYWORDS = {
    "nlp": 3,
    "vision": 3,
    "llm": 3,
    "yoruba": 4,
    "african": 3,
    "agricultur": 3,
}
```

You can also tune the reporting threshold and the default recent-date window:

```python
CLOSING_SOON_DAYS = 7
DEFAULT_RECENT_DAYS = 30
```

The script defaults to showing only competitions that have deadlines within the last 30 days. You can override this with `--days` or the `DIGEST_RECENT_DAYS` environment variable.

## Usage

Run the script normally to fetch competitions and email the digest:

```bash
python competition_digest.py
```

Limit the report to recent deadlines (for example, the last 7 days):

```bash
python competition_digest.py --days 7
```

Include all open competitions instead of the recent-date window:

```bash
python competition_digest.py --all-dates
```

Generate a local report without sending email:

```bash
python competition_digest.py --dry-run
```

This writes:

- `report.html`
- `competitions.csv`

## How the ranking works

Each competition is scored by searching its title, category, description, and tags for matching keywords in `PROFILE_KEYWORDS`.

The weighted score is then used to rank:

- best fit competitions
- competitions closing soon
- newly detected competitions
- competitions with deadline changes

## Output

The generated digest includes:

- platform status for Kaggle and Zindi
- competitions that close within the configured window
- newly discovered competitions
- deadline changes
- top matches by keyword score
- a full list of open competitions

## Troubleshooting

- If Kaggle fails, check that your `KAGGLE_USERNAME` and `KAGGLE_KEY` are valid.
- If Gmail fails, verify that your app password is correct and that 2FA is enabled.
- If no competitions appear, confirm that both APIs are reachable and that your account has access to them.
- If the script returns no results, inspect the logs in the terminal for the source-specific error message.

### Gmail SMTP issue: `SMTPServerDisconnected: Connection unexpectedly closed`

This usually means Gmail closed the connection during authentication or the app is using the wrong credentials.

Common causes:

- the app is using your normal Gmail password instead of a Gmail App Password
- 2-Step Verification is not enabled on the Google account
- the Gmail account is blocking less secure sign-in flows or the app password is invalid
- the SMTP session is being interrupted while Python is authenticating

How to fix it:

1. Enable 2-Step Verification on your Google account.
2. Go to https://myaccount.google.com/apppasswords
3. Generate a new App Password for the app.
4. Use that 16-character password in `GMAIL_APP_PASSWORD` instead of your regular password.
5. Keep `GMAIL_USER` as your full Gmail address.

Example:

```env
GMAIL_USER=you@gmail.com
GMAIL_APP_PASSWORD=abcd efgh ijkl mnop
```

Important: if you ever pasted a real password into a traceback or log, change it immediately and regenerate the app password if needed.
